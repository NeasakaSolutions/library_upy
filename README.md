# Plataforma Digital de Biblioteca Académica — Universidad Politécnica de Yucatán

## 📌 Resumen rápido

Plataforma web académica desarrollada con **Django REST Framework (backend)** y **Vue.js (frontend)** que permite la gestión y consulta de material bibliográfico en formato PDF.

El sistema está diseñado para que **administradores gestionen todo el contenido del sistema**, mientras que los **usuarios pueden acceder, descargar, comentar y organizar material de estudio**.

Desarrollado como parte de prácticas profesionales y servicio social en la Universidad Politécnica de Yucatán.

### 👤 Usuario
